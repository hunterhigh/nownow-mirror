# 观复 Markdown 编辑器契约 v0.1

状态：**P0，不可妥协，未达成前产品不具备发布意义。**

这里的 Markdown 编辑体验不是“点击插入按钮”，也不是“把 `#`、`- [ ]` 等字符放进正文”。它指：用户可以用 Markdown 的书写习惯输入，观复将其即时转换为可继续编辑的语义内容，并能可靠地导入、粘贴、导出和恢复。

## 编辑模型

- `doc_json` 继续是真源；Markdown 是可靠输入／输出协议，不替换现有保存、版本历史、隐私和公开投影。
- 编辑面默认所见即所得，不要求用户在“源码模式”和“预览模式”之间来回切换。
- 文档中的段落、标题、列表、任务、引用、代码、表格等是语义节点，不是带 Markdown 字符的普通文本。
- 所有真实用户编辑进入同一 Undo／Redo 历史；加载、迁移、格式修正等程序事务不得污染撤销栈。

## 必须支持的 Markdown 能力

### 块级

- 普通段落。
- H1、H2、H3。
- 无序列表、有序列表、嵌套列表。
- 任务列表与嵌套任务。
- 引用块。
- 围栏代码块与语言标识。
- 水平分割线。
- GFM 表格。
- 图片与链接。
- Callout／提示块的观复扩展语法。

### 行内

- 粗体、斜体、粗斜体、删除线。
- 行内代码。
- 普通链接、自动链接。
- 高亮 `==text==`。
- 下划线与文字颜色作为观复扩展；不得破坏标准 Markdown 内容。

## 三条等价输入路径

同一种内容必须能通过以下方式得到同一种 Tiptap 节点：

1. **直接 Markdown 快捷输入**：例如行首输入 `## ` 后立即转换为 H2，`- [ ] ` 转换为任务。
2. **Slash 命令**：输入 `/`，搜索并选择内容类型；选择结果是节点转换，不是语法字符插入。
3. **Markdown 粘贴／导入**：粘贴 Markdown 文本或导入 `.md`，解析为相同语义节点。

Slash 的最低键盘契约：输入查询、上下选择、Enter 执行、Esc 关闭；执行后光标位置正确，命令文本被删除，Undo 一次可完整撤销。

## 粘贴、导入与导出

- 普通粘贴保留合理的 HTML 富文本结构。
- 提供明确的“粘贴为 Markdown”能力，并支持识别多行 Markdown。
- `Cmd/Ctrl+Shift+V` 继续执行纯文本粘贴。
- 支持导入 UTF-8 `.md`；导入前展示范围、冲突和图片处理说明，不静默覆盖现有文档。
- 支持单文档与全部文档 Markdown 导出；聚合 Markdown 与可恢复多文档边界的完整备份必须明确区分。
- 标准 Markdown 内容执行 `Markdown → JSON → Markdown → JSON` 后语义等价。

### 观复扩展的可携带规则

- Callout 导出为 `> [!TYPE]` 形式。
- 高亮导出为 `==text==`。
- 文字颜色／下划线允许使用可读 HTML；不支持的消费者仍能读到纯文字。
- @ 成员导出为可读的 `@显示名`，不承诺跨系统恢复成员身份。
- 私密块在用户自己的完整导出中带明确观复注释标记；公开导出永远不含私密内容。
- 日期戳导出为可读日期；重新导入后恢复为日期节点。

## 中文输入与编辑流畅度

- 拼音、双拼、五笔及 macOS 常见中文 IME composition 期间不触发 Slash、Markdown 快捷转换或自动保存副作用。
- composition 结束后不丢字、不重字、不移动光标。
- 连续 Enter／Backspace、跨块选择、拖拽、撤销重做和列表缩进不破坏文档结构。
- 自动保存、离线草稿、冲突重试不得改变光标、选区或撤销历史。
- 5 万中文字符、200 个块的基准文档中，普通输入、选择和滚动不得出现可感知的持续卡顿；测试记录 long task 与保存频率。

## 测试与发布门槛

### 自动测试

- 每一种标准语法至少一个解析、导出和双向语义等价 fixture。
- 嵌套列表、任务、表格、代码语言、链接、图片、Callout、日期戳、颜色、私密块单独覆盖。
- Slash 每一项验证节点类型、触发文字删除、光标和单次 Undo。
- 粘贴分别覆盖 Markdown、HTML、纯文本和图片。
- 现有离线草稿、版本前置条件与空内容保护测试全部继续通过。

### 浏览器验收

- macOS 中文输入法组合输入专项脚本与人工检查。
- 长文、移动端、明暗／多色主题、只读与可编辑状态。
- 键盘全流程不依赖鼠标；菜单焦点和屏幕阅读器名称可用。
- 导入前后、刷新后、离线恢复后、导出再导入后内容一致。

### 完成定义

只有当上述能力在正式 `DocEditor` 中通过，而不是在独立样稿中看起来可用，才能宣称“观复具备 Markdown 编辑体验”。任何解析丢内容、中文输入丢字、导出不可恢复或保存破坏撤销的问题都阻断发布。
