## 当前状态

- 已定位并克隆 `hunterhigh/nownow-mirror`，保留 `main`，本地分支为 `codex/workstation-init`。
- 已沿用正式 `DocEditor` 完成 Markdown 粘贴／导出、默认新建／次选追加导入、语义输入、Callout 可携带规则和长文基线；不是独立样稿。
- 当前自动回归为 9 个测试文件、93 条测试；真实浏览器已验证关键键盘与导入路径，仍需粘贴四路、嵌套结构、正式登录应用及 macOS 中文输入法人工验收。
- 任务模型、独立开发环境与发布目标仍未确定；尚未连接云端数据库、执行迁移或部署。
- 视觉方向已确认以纤细、简约的东方气质继续探索；正式观复 UI 将在编辑器输入契约稳定后整合。

本目录维护项目事实与讨论结论，不复制真实任务内容或密钥。原 README 的安装／部署步骤不是定制版可直接执行的操作手册，先看基线中的环境隔离说明。
